# Требования к уровню сигнала для Acoustic Modem

## Общая информация

Acoustic Modem использует OFDM модуляцию (QPSK/BPSK) для передачи данных через звуковой канал. Для корректной работы системы необходимо соблюдение определенных требований к уровню входного сигнала.

## Целевые параметры сигнала

| Параметр | Значение | Описание |
|----------|----------|----------|
| Частота дискретизации | 48000 Гц | Стандартная частота для акустической связи |
| Целевой RMS символа (SYMBOL_TARGET_RMS) | ~0.1-0.3 | Целевая амплитуда после AGC |
| Целевая амплитуда после эквалайзера | ~0.707 | Для QPSK (1/√2) |
| Минимальный RMS для диагностики | < 0.05 | Выводится предупреждение |

## Особенности работы с телефонами

### Почему телефон может давать более слабый сигнал:

1. **Ограничения аппаратного усилителя** - у телефонов часто стоит программный ограничитель громкости
2. **Аудио эффекты** - эквалайзеры, "улучшайзеры звука", пространственный звук могут искажать сигнал
3. **Передискретизация** - телефон может менять частоту дискретизации (но система к этому устойчива)
4. **Акустические особенности** - динамики телефонов могут иметь другую АЧХ

### Адаптивный эквалайзер и AGC

Система использует два механизма для адаптации к уровню сигнала:

#### 1. AGC (Automatic Gain Control)
- Работает на основе экспоненциального скользящего среднего (EMA)
- Коэффициент сглаживания: `AGC_ALPHA` (по умолчанию 0.3)
- Инициализируется первым измеренным RMS (не 1.0 как раньше!)
- **Обратная связь от эквалайзера**: AGC теперь учитывает амплитуду после эквалайзера для более точной подстройки

#### 2. Адаптивный эквалайзер (AdaptiveEqualizer)
- Использует подход Decision-Directed (DD)
- Коэффициент сглаживания: `alpha` (по умолчанию 0.05)
- **Защита от "развала"**:
  - Минимальная амплитуда Hk: 0.05
  - Максимальная амплитуда Hk: 20.0
  - Сброс к начальному состоянию после 10 символов с низкой амплитудой
- Сохраняет `last_eq_mag` для обратной связи в AGC

## Рекомендации для успешного приема

### С телефона:
1. **Установите громкость на максимум**
2. **Отключите аудио эффекты** на телефоне:
   - Эквалайзер → выключить или "Normal"
   - Surround sound / Пространственный звук → выключить
   - "Улучшайзеры" (Dolby, DTS, etc.) → выключить
3. **Расстояние**: 30-50 см от динамика телефона до микрофона приемника
4. **Ориентация**: экспериментируйте с положением телефона относительно микрофона
5. **Окружение**: избегайте шумных помещений

### С ноутбука:
1. Громкость: 70-100%
2. Расстояние: 50-100 см
3. Избегайте направленных микрофонов (используйте всенаправленные)

## Технические детали реализации

### Обратная связь от эквалайзера к AGC

В файле `modem_rx.py` реализована обратная связь:
- После обработки эквалайзером сохраняется `equalizer.last_eq_mag`
- В глобальную переменную `last_eq_mag_feedback` записывается амплитуда после эквалайзера
- При вычислении `gain_sym` для следующего символа учитывается ошибка: `eq_error = target_eq_mag / last_eq_mag_feedback`
- Коэффициент коррекции ограничен: от 0.5 до 2.0

### Защита от "развала" эквалайзера

Эквалайзер может "развалиться" (сойтись к нулю) на длинных пакетах. Защита включает:
1. Ограничение минимальной амплитуды Hk (0.05)
2. Ограничение максимальной амплитуды Hk (20.0)
3. Сброс к начальному состоянию после N последовательных символов с низкой амплитудой
4. Ограничение изменения Hk за шаг (не более 10%)
