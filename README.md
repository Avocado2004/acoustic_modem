# Acoustic Modem

Проект акустического модема с OFDM модуляцией для передачи данных через звуковой канал.

## Требования для десктопных платформ (Windows, macOS, Linux)

Для запуска GUI необходимо установить следующие зависимости:

- kivy
- sounddevice
- numpy
- scipy
- matplotlib
- reedsolo
- pycryptodome

## Установка зависимостей

```bash
pip install -r requirements.txt
```

## Запуск GUI

Для запуска графического интерфейса используйте:

```bash
python run_gui.py
```

Скрипт `run_gui.py` автоматически проверит наличие всех зависимостей и предостави понятные сообщения об ошибках, если что-то отсутствует.

## Альтернативный способ запуска

Вы также можете запустить GUI напрямую:

```bash
python ofdm_gui_kivy.py
```

Однако рекомендуется использовать `run_gui.py`, так как он выполняет предварительную проверку зависимостей.

## Платформенно-зависимые замечания

- На macOS и Linux аудиобэкенд использует `sounddevice` (PortAudio)
- На Windows также используется `sounddevice`
- Для мобильных платформ (Android, iOS) предусмотрены отдельные бэкенды, но они пока не реализованы полностью
- Код использует относительные пути и должен работать одинаково на всех поддерживаемых платформах

## Структура проекта

- `ofdm_gui_kivy.py` - основной GUI на Kivy
- `audio_backend.py` - абстракция аудио с поддержкой разных платформ
- `test_modem_simple.py` - основной модуль модема
- `run_gui.py` - скрипт запуска с проверкой зависимостей
- `requirements.txt` - список зависимостей для десктопов
